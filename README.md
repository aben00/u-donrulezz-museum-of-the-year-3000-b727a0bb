A single museum label for the year 3000: one line, at most 200 characters, written for an ordinary object from today — the TV remote control. It imagines a future visitor reading the plaque next to a wand that once changed channels from across the room, until it slipped between the sofa cushions, where it remains to this day.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

This writes `entry.txt` into the output directory and self-checks that the entry is exactly one line and no longer than 200 characters.
